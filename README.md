# 4-Qubit Flip-Chip Transmon Processor

> **VLSID Design Contest 2026 — Finalist**

A 3D-integrated qubit processor designed to cut crosstalk without adding routing congestion.

## Highlights

- Designed a Q-chip/C-chip flip-chip architecture in Qiskit Metal to physically separate qubits from control/readout routing
- EM-verified coherence improvement from ~3.02 µs to ~4.94 µs and crosstalk reduction from ~−37 dB to ~−55 dB
- Paired the processor with a quantum-ML behavioral biometric model for human-vs-bot classification

## Tooling

`Qiskit Metal` · `Keysight ADS QuantumPro` · `Ansys HFSS` · `GDS Export`
